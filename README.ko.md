## Amazon 서술형 리뷰 수집과 분석

`amazon-review-scraper`

정확한 ASIN의 서술형 리뷰를 수집·분석하고 보수적으로 중복 제거하여 추적 가능한 표와 오프라인 보고서를 만듭니다.

스킬 디렉터리: `.`

**구현 근거와 의존성**

Python 3.10+, XLSX는 openpyxl, 이미지 삽입은 선택 Pillow. Woot는 미국 전용이며 ASIN/offer 정확 일치가 필요합니다. 다른 시장은 가용한 승인 커넥터/브라우저가 필요합니다.

**입력**

수집: ASIN/URL·시장, 선택 날짜/별점/수량. 분석 전용: 제공 JSON/CSV/XLSX/HTML. 산출물과 개인정보 권한을 정하고 완전한 기존 파일은 다시 수집하지 않습니다.

**출력**

ASIN별 원본·상태, 표준 JSON, 요청 XLSX/CSV/미디어 URL, 단일 HTML 및 선택 VOC 전달. 원문·번역·요약은 분리합니다.

[실행 절차 · 제약과 중단 조건 · 요청 예시](references/i18n/ko.md)

> 다음 스킬을 사용하세요: `$amazon-review-scraper` — 기존 거치대 리뷰의 원문을 보존하고 한국어로 반복 문제와 표본 한계를 설명하되 실제 고장률을 주장하지 않습니다. 한국어로 답하고 근거, 미확인 사항과 작업 권한을 유지하세요.

## 언어 지원과 검증

이 문서는 목적, 전제, 입출력, 절차, 예시와 제약을 다루는 한국어 운영 가이드이며 모든 참고 문서의 문장별 번역은 아닙니다. 상세 기술 자료, 과거 사례, 스크립트 오류, 예제 화면과 이미지는 원래 언어를 유지합니다. 요청 시 해당 언어로 설명할 수 있습니다. 구조, 링크와 핵심 제약을 확인했으나 각 언어 원어민 교정은 수행하지 않았습니다.

전달 전에 입력, 근거, 결측값, 출력 파일과 원래 완료 기준을 대조합니다. 실행하지 않은 단계는 미검증으로 표시하며 스크립트의 정상 종료를 업무 검증 성공으로 취급하지 않습니다.
