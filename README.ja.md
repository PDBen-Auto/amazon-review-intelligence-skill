## Amazon 文章レビュー収集と分析

`amazon-review-scraper`

正確な ASIN の文章レビューを収集または分析し、保守的に重複排除して追跡可能な表とオフラインレポートを作ります。

スキルディレクトリ: `.`

**実装の根拠と依存関係**

Python 3.10+、XLSX は openpyxl、画像埋込は任意の Pillow。Woot は米国限定で ASIN と offer の一致が必要。他国には利用可能な許可済み接続やブラウザが必要です。

**入力**

収集：ASIN/URL と市場、任意の日付・星・件数。分析のみ：手持ち JSON/CSV/XLSX/HTML。成果と個人情報権限を指定し、完全な既存資料を再収集しません。

**出力**

ASIN 別原資料・状態、標準 JSON、必要な XLSX/CSV/メディア URL、単一 HTML、任意の VOC 引継ぎ。原文、翻訳、要約を別々に保持します。

[実行手順 · 制約と停止条件 · 依頼例](references/i18n/ja.md)

> 次のスキルを使用してください： `$amazon-review-scraper` — 手持ちレビューを分析し、原文を残して日本語で反復問題を説明し、サンプルの限界を示します。日本語で回答し、根拠、不明点、操作権限を維持してください。

## 言語対応と検証

本書は目的、前提、入出力、手順、例、制約をまとめた日本語運用ガイドです。全参考資料の逐語訳ではありません。詳細技術資料、過去事例、スクリプトのエラー、サンプル画面、画像は原言語のままです。必要に応じて日本語で説明できます。構造・リンク・重要制約を確認していますが、各言語の母語話者による校閲は未実施です。

納品前に入力、根拠、欠損、出力ファイルと元の完了条件を照合します。未実行の工程は未検証とし、終了コードの成功を業務上の検証成功と混同しません。
