# Public Positioning

## 一句话定位

一个把 Amazon written reviews 变成可追溯产品决策证据的本地优先工作流：采集、去重、原声保留、Excel 交付、离线洞察和改进假设在同一条链路完成。

## 对产品团队的直接价值

### 采集结果可以复核

每条评论保留原文、来源、日期、链接和稳定标识；中文翻译与摘要单独保存。团队可以从结论回到原声，而不是只能相信一段不可解释的情感分数。

### 结论可以进入下一步工作

报告将差评和好评归因到单一主问题/主卖点，同时保留二级标签，进一步整理为需求主题、换品牌触发器、改进优先级和验证问题。输出可以继续交给 VOC、Discovery、战卡、PRD 或证据合同流程。

### 数据口径不夸大

written reviews、ratings 总数、接口返回量、浏览器可见样本和去重后有效评论分开记录。结果会显示缺口和停止原因，不用“全量”“真实占比”等未经证据支持的措辞。

### 适合真实工作节奏

支持单 ASIN、批量 ASIN、断点续跑和 analysis-only。公开评论主路径无需 Amazon 账号，输出为 JSON、Excel 和无需联网的 HTML，方便在本地、团队共享盘或后续 BI 流程中复核。

## 适用场景

- 新品立项前：快速判断用户最在意的需求和高风险问题。
- 竞品研究：从竞品原声中提炼弱点和换品牌触发器。
- 版本迭代：把高频差评转成结构、说明书、包装、适配性和 Listing 改进项。
- 运营复盘：按星级、主题、日期和变体检查反馈变化。

## 边界

它不替代商业级代理基础设施、统计抽样、用户访谈或私有客服数据分析。它的优势是让公开 Amazon 评论从“抓到一些文本”变成“可回溯、可交付、能推动产品动作的证据层”。
