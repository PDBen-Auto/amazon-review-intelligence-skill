# Licensing and edition policy

This repository currently uses a source-available license. That choice keeps the public Skill, examples, validation scripts, and release provenance inspectable while reserving the publisher's right to control official releases and commercial terms.

## Public edition

The public package includes the Skill instructions, documented schemas, synthetic fixtures, deterministic scripts, and offline report examples. Anyone may inspect the source and run it within the rights granted by `LICENSE`.

## Reserved material

The following are not included in this repository and remain separately controlled:

- customer review collections and private research bundles;
- unpublished adapters, operational credentials, and private deployment configuration;
- commercial support, managed collection, and custom integration work;
- any future private scoring, prioritization, or client-specific methods.

## Official release status

An altered fork may be useful, but it is not an official PDBen-Auto release unless the release manifest and publisher provenance signature verify. See `RELEASE_PROVENANCE.json` and `PUBLISHER_PUBLIC_KEY.pem`.

This file explains the edition boundary; it does not grant rights beyond `LICENSE` and is not legal advice.
